# Personal-Book-Tracker
AI-Assisted Development - Exam


Personal Book Tracker (“Mini Goodreads”). 

You search for books using the free Open Library API (no key needed), add them to shelves (“Want to Read”, “Reading”, “Finished”), track reading progress by page, rate and review finished books, and set a yearly reading goal. A stats page shows books per month, pages read, favorite genres, and progress toward your goal. 

It works well for the exam because it combines an external API integration, your own database, user-specific data, and a stats/visualization layer, so each module is genuinely different. Book covers also make the screenshots look polished with almost no design effort.
